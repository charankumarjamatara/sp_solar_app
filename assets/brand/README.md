# SP Solar Solutions — Brand Assets

Place the official company logo files in this directory:

- `logo-full.png` / `logo-full.svg`: Full horizontal or stacked SP Solar Solutions logo with text & "Since 2026".
- `logo-monogram.png` / `logo-monogram.svg`: SP icon/monogram mark for compact branding and app icons.
- `logo-white.png`: White/Gold version for deep navy backgrounds (`#001735`).

The application components (`components/brand/BrandLogo.tsx` and `components/brand/BrandMonogram.tsx`) will automatically render the supplied logo assets and provide a clean vector brand fallback.
